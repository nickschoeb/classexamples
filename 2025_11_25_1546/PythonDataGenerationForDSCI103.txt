First, install the Faker lib by running the cell below

!pip install Faker

Next, import Faker so we can use it

from faker import Faker
fake = Faker()

First we should explore some providers that Faker has. See below for some name parts. Use this cell to test out some of the data you want to use.

print(fake.first_name())

Documentation for Faker: https://faker.readthedocs.io/en/master/#

Providers: https://faker.readthedocs.io/en/master/#providers

This is a loop to generate some data you can copy into somehwere else.

# First name
for _ in range(5):
    print(fake.first_name())

If you are trying to make some inserts like: "INSERT INTO people (LastName, FirstName)" VALUES ('Smith', 'John');" Use String concatenation like below:

print("INSERT INTO people (LastName, FirstName)\" VALUES ('" + fake.last_name() + "', '" + fake.first_name() + "');")

Then just put this into a loop, note that this is unrelated data that has no dependency.

for _ in range(5):
    print("INSERT INTO people (LastName, FirstName)\" VALUES ('" + fake.last_name() + "', '" + fake.first_name() + "');")

If you need to use a generated value in a later query save generated data into variables.

last_name = fake.last_name();
first_name = fake.last_name();
print(last_name)
print(first_name)

print("INSERT INTO people (LastName, FirstName)\" VALUES ('" + last_name + "', '" + first_name + "');")
print("INSERT INTO other_table (PersonId, OtherStuff)\" VALUES ((SELECT PersonId FROM people WHERE LastName = '" + \
      last_name + "' AND FirstName = '" + first_name + "'), 25.4);")
